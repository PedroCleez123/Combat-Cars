# Archivo técnico

Esta carpeta almacena artefactos técnicos grandes que no intervienen en el
desarrollo normal y no deben aparecer junto al código activo.

- `rocketsim-builds/2026-10-16/` conserva cinco directorios de compilación
  históricos de RocketSim. No contiene la build activa.

La build de desarrollo es exclusivamente
`.rocketsim-bridge-build-r9/rocketsim_bridge-r19.exe`. Los directorios bajo
`rocketsim-builds/` están ignorados por Git y se conservan para trazabilidad o
para repetir una sonda histórica. No se deben seleccionar al iniciar el juego.
