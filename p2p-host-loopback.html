Prueba P2P de autoridad y snapshots

Prueba opt-in de una simulación ArenaMatch JavaScript ejecutada por el host local. El piloto envía controles; sólo el host avanza la física y transmite snapshots compactos por WebRTC.

Esto no es una partida ni comprueba conectividad exterior. Los dos peers se crean en este navegador. No hay señalización, matchmaking, STUN/TURN ni servidor remoto.
